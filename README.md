# proxmox-scripts

Hjælpescripts jeg kører på mine PVE-noder. Komplement til [pve-setup](https://github.com/allansodk/pve-setup).

| Script | Hvad |
|--------|------|
| `snapshot-all.sh` | Snapshot af alle kørende guests |
| `bulk-backup.sh` | vzdump af alt til NAS |
| `lxc-update.sh` | `apt upgrade` i alle LXC-containere |

Mere på <https://allanso.dk/homelab>.
